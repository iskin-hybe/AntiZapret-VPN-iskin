## Общие советы

- Ставить VPN на серверы, которые не жалко потерять; для тестов брать посуточную оплату; торренты приводят к абузам; SMTP хостеры закрывают, поэтому Outlook в полном VPN почту не отправит [АВТОР] (#83680, #84871, #86139, #87198).
- Любой хостинг, работающий в РФ, отключит сервер по письму РКН [АВТОР] (#69705).
- Мелкие дешёвые хостеры: оверселл, узкие каналы, «палёные» IP, Google-регион раз в несколько месяцев уезжает в RU или GB. Чистые IP вероятнее у иностранных хостеров без оплаты российскими картами и криптой [3 польз.] (#92087, #92513, #95539). Удобен хостинг с пробным днём (#93705).
- DNS своих доменов держать за рубежом: 02.11 Beget лёг целиком вместе с DNS [АВТОР] (#100692). В профилях указывать домен, тогда при смене IP достаточно поправить A-запись (#81960, #96544). Вариант: .org у spaceship и DNS на desec.io (обязателен DNSSEC, паспорт не нужен) [1 польз.] (#94128); на DuckDNS нельзя повесить несколько A-записей на одно имя (#92885).
- Хостеры режут исходящий 80/443, поэтому `proxy.sh` ходит на основной сервер по 50000-м портам [АВТОР] (04.05, #80685).
- Доходит ли хостер до Telegram: `nc -vz api.telegram.org 443` [1 польз.] (#91310). 09–10.09 с серверов нескольких хостеров (NL, DE, RU) были недоступны DC Telegram 91.105.192–193.x:443 [3 польз.] (#94689, #94710, #94739, #94746).
- Банят подсети хостеров: /24, в январе вплоть до /8; волны 15.01 и 04.08 [АВТОР] (#60149, #64115, #91029).

## Страны и регионы

- Постсоветские страны — плохой выбор: из Казахстана Google отдаёт кэш в РФ (Самара), отсюда блоки. Проверка: `redirector.googlevideo.com/report_mapping?di=no` [АВТОР] (23.01, #60871, #60884).
- Финляндия перегружена, только для тестов [АВТОР] (#60065). Маршрут к медиа-CDN Telegram (DC203) с H2 и ряда хостингов идёт через RETN Helsinki и подвисает (09–15.09, #94605, #94718).
- Германия: Aeza DE автор рекомендовал (см. ниже). Срез 05.08: Франкфурт работал полностью, у Aeza США и Senko FI проходил только AWG, 4VPS FR не работал совсем [1 польз.] (#91188).
- WARP хорош, когда до эндпоинта ~1 мс (Cloudflare в том же ДЦ); из Армении работает плохо. Выход WARP — в стране входа, страну не выбрать [АВТОР] (#66342, #77521, #77618).
- Мнения без проверки: Азия и Турция живут дольше «грязной» Европы, США — месяц-полтора (#98336, #99019).

## Геолокация Google, реклама YouTube, Gemini

- Google может менять геолокацию IP хостинга (DE → RU → снова DE). Если IP считается российским, Gemini не работает: нужна смена IP или DNS с обходом [АВТОР + 1 польз.] (#68395, #92982, #93857). Примеры: шведский IP Aeza временами RU (#91927, #93411); в Австрии у Aeza WARP-IP определялся как RU (#98423); старые IP H2 Google годами не считал российскими (#99269).
- С 14.08 Gemini через WARP не работает: Google заблокировал подсеть WARP и считает её IP российскими; альтернатива — Proton VPN [АВТОР + много польз.] (#91987, #92036, #92049, #97031).
- Реклама YouTube/TikTok — «лотерея» по IP и региону сервера [АВТОР + 3 польз.]: без рекламы были DigitalOcean NL, Aeza и часть IP dhostVPS DE; на сервере в LV (регион HK) реклама появилась (#59561, #59741, #91501, #93137, #95514, #95945). Через WARP YouTube видит регион GB (#65649). Блокировкой доменов рекламу YouTube не убрать (#70517).
- Aeza: Patreon банит её ASN, Grok не работает (янв.–февр., #64262, #64785).
- Google помечает подсеть как RU, если через неё сидит много русскоязычных пользователей; чистый IP держится от недели до ~3 недель; проверка — скрипт ipregion [1 польз., с ним спорят] (15.07, 4VPS #82003, #82054, #82065). Албания — в списке стран, где YouTube не монетизируется (4VPS #82075). Видеорекламу DNS-блокировщики не режут: она идёт с тех же доменов, что видео (4VPS #51095, #82036).
